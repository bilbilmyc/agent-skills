# Frontend Animation Skill

## Purpose

Control AI generated animations. Motion should improve understanding, not decorate the page.

## Rules

Prefer:
- subtle transitions
- meaningful state changes
- natural interaction feedback

Avoid:
- excessive gradients
- loading animations everywhere
- large entrance animations
- distracting effects

## Responsive

Animations must adapt to device capability.

Do not assume fixed viewport size.
Respect reduced motion preferences.
