# Frontend Accessibility Skill

## Purpose

Ensure frontend products are usable and standards compliant.

## Rules

Always consider:

- semantic HTML
- keyboard navigation
- focus states
- screen reader compatibility
- color contrast

Avoid:

- clickable div without reason
- missing labels
- inaccessible dialogs
- relying only on color

## Implementation

Prefer:

- native HTML elements
- ARIA only when required
- predictable interaction patterns
