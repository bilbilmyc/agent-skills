# Frontend Review Skill

## Purpose

Review AI generated frontend implementations.

## Check

### Product

- Does layout match product type?
- Is this accidentally an admin dashboard?

### Visual

- Typography hierarchy
- Spacing consistency
- Color consistency
- Component reuse

### Engineering

- Responsive behavior
- Accessibility
- Performance
- Maintainability

## Output

Generate a review report with:

- problems
- severity
- recommended changes
