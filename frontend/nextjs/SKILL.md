# Next.js Frontend Skill

## Purpose

Build production Next.js applications.

## Rules

Prefer:

- server components when possible
- clear data boundaries
- predictable routing
- reusable components

Avoid:

- unnecessary client components
- duplicated fetching logic
- large page components
- uncontrolled state management

Consider:

- SEO
- performance
- caching
- loading states
- error states
