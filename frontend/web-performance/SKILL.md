# Web Performance Skill

## Purpose

Build fast frontend applications.

## Rules

Avoid:

- unnecessary client components
- huge initial bundles
- blocking requests
- unoptimized images

Prefer:

- server rendering when appropriate
- lazy loading
- streaming
- optimized assets
- measured performance

## Responsive Requirement

Never optimize for a fixed screen size.

Layouts must adapt to:

- desktop monitors
- laptops
- tablets
- mobile devices
- different browser widths

Do not use hard-coded page widths as the primary layout strategy.
