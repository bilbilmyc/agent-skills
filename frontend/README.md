# Frontend Skills

Frontend skills are organized around three execution phases.

## 1. Product Design

Path: `frontend/product-design`

Use before coding.

Responsible for:
- product classification
- information architecture
- page structure
- responsive UX decisions
- avoiding admin dashboard patterns

## 2. Engineering

Path: `frontend/engineering`

Use during implementation.

Responsible for:
- React
- Next.js
- TypeScript
- component design
- state management
- data fetching
- performance

## 3. Review

Path: `frontend/review`

Use before delivery.

Responsible for:
- product alignment
- responsive validation
- UI consistency
- engineering quality

## Design Rule

All frontend products must be responsive.

Never design for a fixed canvas or a single viewport.

Prefer:
- fluid layouts
- content-driven sizing
- CSS grid/flex
- adaptive typography
