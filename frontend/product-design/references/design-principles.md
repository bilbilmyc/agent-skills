# Design Principles

## Product First

A frontend is an interface for user goals, not a collection of components.

## Information Hierarchy

Every page should answer:

- What is important?
- What should users do next?
- What can be ignored?

## Layout Selection

Choose layout based on user workflow.

Content consumption:

- top navigation
- reading column
- discovery areas

Operations:

- sidebar
- tables
- forms

## Visual Quality

High quality interfaces require:

- spacing system
- typography system
- consistent components
- responsive behavior
- intentional interaction
