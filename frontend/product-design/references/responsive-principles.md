# Responsive Principles

## Core Rule

Frontend products are fluid systems, not fixed screenshots.

Never design around a single viewport.

## Forbidden

- fixed desktop canvas
- 1440px assumptions
- fixed height application shells
- shrinking desktop layouts for mobile

## Prefer

- CSS grid and flexbox
- min/max constraints
- fluid typography
- content-driven sizing
- viewport-aware composition

## Validation

Check:

- desktop wide screens
- laptop screens
- tablets
- mobile screens

The layout should adapt instead of collapse.
