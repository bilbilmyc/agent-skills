# Frontend UI System Skill

## Purpose

Create consistent product interfaces instead of isolated AI generated pages.

## Rules

Before creating components define:

- design tokens
- typography scale
- spacing system
- color system
- component hierarchy

## Avoid

- random spacing values
- one-off components
- inconsistent button styles
- page-specific CSS hacks

## Output

When designing a UI system provide:

1. tokens
2. component rules
3. usage examples
4. review checklist
